# PC-health-check
A python tool that performs system diagnostics and network connectivity checks.
This project is a beginner-friendly IT diagnostic tool written in Python. It performs a full system health check and basic network connectivity tests.
Features
CPU, RAM, and disk usage reporting
DNS resolution test
Gateway reachable test
Internet connectivity
